Case study / Independent project

The meaning
behind the numbers.

Exploring Norwegian Offshore Directorate production data through ingestion, quality checks, modelling and visualisation.

The work

This self-directed project follows the analysis chain from source data to a dimensional model and Power BI reports. Python supports ingestion, transformation, data-quality auditing and decline-curve analysis.

The interesting problem was meaning

Negative monthly volumes can reflect restatements or re-injection accounting. A missing month is different from a month with zero production. Earlier produced-water values can represent non-reporting rather than a dry field.

Those distinctions matter: a superficially clean dataset can still lead to misleading conclusions if the transformations erase its meaning.

From data to explanation

A field dimension, monthly production fact table and date table support a Power BI model. Reports examine the shelf overall, individual field lifecycles and production concentration. Forecasting experiments compare a physical decline model with gradient boosting.

Scope

This is independent study, including the Power BI and DAX work, rather than commercial analytics experience. The project is local; there is no public repository linked here.
