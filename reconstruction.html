Group coursework / 3D computer vision

3D reconstruction

A group project working through image undistortion, camera poses, feature correspondences, depth scaling and point-cloud generation.

Project overview

The project uses nine colour images, corresponding depth images and calibration information to work towards a merged coloured point cloud. These figures show intermediate outputs from the submitted notebook.

Collaborative work

Submitted by Zahra Parvinashtiani, Behnam Pourafkham and Fatemeh Rezaei. The visuals shown here belong to the group submission.

The room imagery is supplied course data; the marked features and camera-pose plots are saved notebook outputs.
