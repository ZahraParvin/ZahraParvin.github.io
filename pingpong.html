Case study / NTNU coursework

Embedded ping-pong game

An electromechanical ping-pong project combining firmware, communication and control.

The system

A hand-held controller node and a machine-control node exchange commands over CAN. Sensor inputs and joystick commands connect to a physical paddle driven by a motor.

Implementation

The work included bare-metal ATmega162 drivers for SPI, I2C, UART, timers, interrupts and external SRAM. CAN work covered frame construction, message IDs and filtering across the two microcontrollers.

PWM motor drive and encoder feedback support closed-loop paddle positioning. Analogue and infrared inputs involve ADC conversion, debouncing and signal conditioning.

What the project involved

This coursework project gave me practical experience with communication between devices, low-level C and motor control.
